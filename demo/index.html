V1.5 · The problem we solved

The mentor was mishearing the math

Indian academic speech is wildly code-mixed — English "cos theta" next to Hindi "lambit karan" (perpendicular) in one breath. Deepgram nova-3 mangles equation words.

  • ✗"sin x" heard as "signs"
  • ✗"cos theta" heard as "kos theta"
  • ✗"avkalan" (derivative) → "अब कलं" (≈ "now pen")
V1 — the only defense
One paragraph in the mentor prompt begging the LLM to guess through mishearings.

A bypass: the error is never prevented, and correction competes with persona, mood, safety & mode-switching for attention in a single prompt.

V1.5 · The fix

Two dedicated layers, not a prompt patch

🧠 Mentor LLM

🛡️

Layer 1 — keyterm boosting

A curated lexicon (trig, calculus, Hindi physics, chemistry) seeded into nova-3's keyterm prompting, auto-extended per student by track & weak topics. Prevents mishears before they happen — +0ms.

⚡

Layer 2 — conditional normalizer

A fast Haiku pass on LiveKit's stt_node() hook, but only when text looks academic or confidence is low. Chit-chat passes through untouched. Timeout-guarded, never blocks the voice loop.

And we retired the bypass: the heavy "hear the math" block was removed from the mentor prompt. Correction now lives where it belongs.

V1.5 · Results · what's next

Honest about the edges

⏱️

Normalizer latency

Mean 1249ms, p95 2553ms — only ~75% finish inside the 1.5s budget, so ~25% fall back to raw text. The OpenRouter→Haiku hop is the cost; worth tuning.

🎯

Gate recall on total garbles

Fully-mangled terms ("electro file") don't trigger the text gate — caught in production by the low-confidence trigger + Layer 1 keyterms instead.

🔊

Synthetic audio

Layer 1 audio is now the app's own Cartesia voice (Hindi) — more realistic, but still synthetic & single-voice. A human-recorded gold set is the next step.

✂️

Action: trim the keyterm list

On the app voice the ~49-term list reproducibly drops whole "lambit karan" utterances to empty. A 15-term high-value list = same recovery, 0 regressions. Trim before shipping wider.
