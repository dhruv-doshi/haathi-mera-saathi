Self-updating profile

After each call an LLM extracts what changed — topics that improved, new weak spots, scores, commitments — into a learned layer merged on top of your profile.

"SN1/SN2 finally clicked — but Thermo feels shaky. I'll redo the substitution set."

The hand-authored profile is a frozen seed — learnings live in a separate layer, so an LLM slip can never corrupt ground truth. No paid services.
Safe for minors

Safety is a guarantee, not a hope

Saathi serves minors. Catching distress can't depend on the model choosing to — so there's a deterministic layer underneath the LLM.

Prompt-only — a hope
"Please escalate if the student is in distress…"

The LLM might miss it, paraphrase the helpline away, or be talked past.

→
Code-level — a guarantee
Detected in the transcript → helpline spoken via TTS, every time.

Independent of the model. The number can't be dropped or refused.

Hears you right

It actually hears the math

Code-mixed equation words wreck normal speech-to-text — "sin x" → "signs", "avkalan" (derivative) → "ab kalam" (now pen). Two dedicated layers fix it before the mentor ever sees the text.

🛡️

Prevent + correct

A per-student academic lexicon biases the STT at the source (+0ms), and a fast conditional pass repairs what slips through — only on academic or low-confidence turns. Casual chat passes untouched.
